### 🚀 Proyectos Destacados

#### 🧪 [TobiTests — Framework Autónomo Multi-Agente de QA E2E](https://github.com/TodoTobi/tobitests) ⭐ *proyecto principal*
*Python · TypeScript · Playwright · MCP · Chrome DevTools CDP · React + Vite*
- Framework de QA autónomo local-first que combina Playwright MCP, Chrome DevTools MCP y agentes de IA (Antigravity, Claude Code, OpenCode, Cursor…) para generar, ejecutar y diagnosticar pruebas E2E sin cuotas en la nube.
- Oráculo de detección de bugs en 3 capas: CDP implícito (consola/red), divergencia de estado (código fuente white-box vs. DOM en vivo) y visual y accesibilidad.
- Incluye servidor MCP nativo (`tobitests-mcp`), CLI (`tobitests`), documentación bilingüe (EN + ES) y un dashboard 2.5D Isométrico de Oficina de Agentes.
- 📄 [Documentación en Inglés](https://github.com/TodoTobi/tobitests/blob/main/README.md) · [Documentación en Español](https://github.com/TodoTobi/tobitests/blob/main/README.es.md)

#### 🗓️ [Ritmo — Motor Inteligente de Enfoque y Gestión del Tiempo](https://github.com/TodoTobi/ritmo-calendario-pro)
*Next.js 14 (App Router) · TypeScript · Supabase (PostgreSQL 16) · Google Gemini 2.0 Flash · Telegram Bot API*
- Sistema de gestión del tiempo basado en jerarquías matemáticas de bloques horarios, con Gemini 2.0 Flash y manejo de errores RFC 7807. Tope de $0/mes de costo operativo.

#### 👁️ [Sintaxia — Chatbot Educativo de TICs con Visión y Visor 3D](https://github.com/TodoTobi/Syntaxia_GIT)
*Python · Flask · YOLOv5 · OpenCV · Three.js · Groq API*
- Chatbot educativo para la especialidad TICs que combina detección por visión por computadora con YOLOv5 y un visor 3D web en Three.js para modelos `.obj`.

#### 🎫 [Ticket System — API Help Desk para Aulas de Informática](https://github.com/TodoTobi/ticket-system)
